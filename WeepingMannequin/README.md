# WeepingMannequin

Плагин для Paper 1.21.11 (Java 21): манекен (Armor Stand) подкрадывается к ближайшему игроку, пока на него не смотрят, и замирает, как только попадает в поле зрения.

## Команды (право `mannequin.admin`, по умолчанию op)
- `/mannequin spawn` — создать манекена там, где вы стоите
- `/mannequin remove` — удалить всех манекенов
- `/mannequin list` — список с координатами

## Сборка на GitHub
1. Создайте репозиторий и загрузите содержимое этой папки (pom.xml должен лежать в корне репозитория).
2. Откройте вкладку **Actions** — сборка запустится сама после push.
3. Готовый `.jar` скачайте из **Artifacts** в завершённом запуске.
4. Для релиза: создайте тег `v1.0.0` — jar приложится к GitHub Release.

## Локальная сборка
```
mvn clean package
```
Jar появится в `target/`. Положите его в папку `plugins/` сервера.

Настройки — в `plugins/WeepingMannequin/config.yml`, позиции манекенов — в `data.yml`.
